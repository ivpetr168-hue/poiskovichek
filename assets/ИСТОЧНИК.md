# Источник словаря словоформ `morph.fst`

## Происхождение данных
Файл `morph.fst` собран из морфологического словаря проекта [pymorphy3-dicts-ru](https://pypi.org/project/pymorphy3-dicts-ru/) (репозиторий: https://github.com/no-plagiarism/pymorphy3-dicts) на основе данных корпуса русского языка [OpenCorpora](https://opencorpora.org/). Точная версия исходного пакета в доступных файлах репозитория не зафиксирована.

Словарь содержит свыше 3,06 млн нормализованных словоформ русского языка и более 182 тыс. уникальных лексем.

## Как пересобрать словарь
Для пересборки `morph.fst` используется встроенный бинарный инструмент `build_morph`:

```powershell
cargo run --release --bin build_morph -- `
    "путь\к\morphology.sqlite3" `
    "assets\morph.fst"
```

Инструмент:
1. Считывает все пары `(word, lexeme_id)` из базы данных `morphology.sqlite3` (`word_primary`).
2. Нормализует формы: приводит к нижнему регистру по стандарту Unicode и заменяет букву «ё» на «е».
3. Объединяет лексемы для одинаковых нормализованных форм (включая пары «все» / «всё» и омонимы «стали»).
4. Формирует единый компактный файл `morph.fst`:
   - Заголовок с сигнатурой `PKMORPH1`, версией формата, счётчиками форм и лексем и контрольной суммой CRC32;
   - FST (`fst` 0.4) отображение «нормализованная форма → смещение в таблице лексем»;
   - Дедуплицированную таблицу отсортированных списков номеров лексем (`u32`).
