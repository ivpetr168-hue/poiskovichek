# Настройки программы «ПоисКовичеК»

Окно настроек вызывается через пункт меню действий **«Настройки»** в правом верхнем углу главного окна. В окне доступны 7 вкладок, позволяющих детально сконфигурировать поведение программы, область поиска, исключения, правила извлечения текста и производительность.

В нижней части окна настроек расположены кнопки:
- **Сохранить** — сохраняет все изменения в конфигурационный файл `%APPDATA%\ПоисКовичеК\settings.toml` (или `settings.toml` рядом с исполняемым файлом в переносном режиме).
- **Отмена** — закрывает окно настроек без сохранения внесённых изменений.
- **Вернуть умолчания** — сбрасывает все параметры программы к исходным заводским значениям.

---

## 1. Вкладка «Источники»

Определяет список индексируемых дисков, папок и файлов, а также индивидуальные параметры их обработки.

| Настройка | Что делает | Умолчание |
|---|---|---|
| **Список источников** | Таблица источников индексирования. Для каждого источника отображаются: путь, режим индексирования, предельная глубина вложенности, переключатель активности (вкл/выкл) и кнопка удаления. | Формируется в мастере первого запуска |
| **Режим источника** | Определяет полноту анализа файлов в источнике:<br>• `Полностью` — индексируются имена, свойства и содержимое всех поддерживаемых форматов файлов.<br>• `Только документы` — индексируются только офисные документы и книги, исключая код и служебные файлы.<br>• `Только имена` — извлечение содержимого отключено, индексируются только имена файлов и свойства. | `Полностью` |
| **Предельная глубина** | Максимальный уровень вложенности подпапок при обходе (0 — без ограничения глубины). | `0` (без ограничений) |
| **Активность источника** | Включение или временное отключение источника без его удаления из списка. | `Включён` |
| **Добавить диск или папку** | Вызов системного диалога выбора папки для добавления нового источника поиска. | — |
| **Добавить файлы** | Вызов системного диалога выбора отдельных файлов для добавления в поисковый индекс (индексируются файлы любого формата). | — |

## 2. Вкладка «Исключения»

Правила фильтрации файлов и папок, которые пропускаются при обходе дисков и не попадают в поисковую базу.

| Настройка | Что делает | Умолчание |
|---|---|---|
| **Имена папок** | Список имён каталогов (шаблонов), которые полностью игнорируются при обходе файловой системы (системы контроля версий, виртуальные окружения, кэши компиляторов и пакетов). | `.git .svn .hg node_modules __pycache__ .pytest_cache .mypy_cache .ruff_cache .cache .tmp .venv venv site-packages target` |
| **Папки «только документы»** | Имена папок, для содержимого которых автоматически включается щадящий режим «только документы» (служебные файлы и исходный код внутри них не анализируются). | `tmp cache` |
| **Системные пути** | Список системных и временных каталогов, пропускаемых при сканировании томов (папки ОС Windows, корзина, точки восстановления, системные профили). | `%WINDIR%`, `Program Files`, `Program Files (x86)`, `ProgramData`, `$Recycle.Bin`, `System Volume Information`, `Recovery`, `PerfLogs`, `%LOCALAPPDATA%`, `%APPDATA%` |
| **Файлы-исключения** | Шаблоны имён служебных и временных файлов операционной системы, которые исключаются из индексирования. | `hiberfil.sys pagefile.sys swapfile.sys dumpstack.log dumpstack.log.tmp ntuser.dat* ~$*` |

## 3. Вкладка «Форматы и пределы»

Управление извлечением текста из различных форматов файлов, ограничениями объёма и таймаутами.

| Настройка | Что делает | Умолчание |
|---|---|---|
| **Текстовые форматы** | Извлечение текста из файлов простого текста и кода (`txt`, `md`, `csv`, `json`, `jsonl`, `xml`, `yaml`, `ini`, `log`, исходный код). Автоматически определяются кодировки UTF-8, UTF-16, UTF-32, CP1251, CP866. | `Включено` |
| **Офисные форматы** | Извлечение содержимого из офисных документов (`docx`, `xlsx`, `pptx`, `odt`, `ods`, `odp`). Включает основной текст, таблицы, сноски и колонтитулы. | `Включено` |
| **Книги и разметка** | Извлечение текста из электронных книг и разметки (`html`, `htm`, `rtf`, `fb2`, `epub`). В EPUB текст читается строго по порядку чтения (spine). | `Включено` |
| **PDF-документы** | Извлечение текстового слоя из файлов PDF. Если текстовый слой отсутствует, файл помечается как «скан, нужен OCR». | `Включено` |
| **Предел: книги и документы** | Максимальное количество извлекаемых символов из одного файла книги или офисного документа. | `20 000 000` символов |
| **Предел: код и служебные** | Максимальное количество извлекаемых символов из файлов исходного кода и служебных конфигураций. | `200 000` символов |
| **Предел: прочие форматы** | Максимальное количество извлекаемых символов для остальных типов файлов. | `100 000` символов |
| **Предел: большой txt/md** | Ограничение количества символов для текстовых файлов, чей размер превышает заданный порог. | `200 000` символов |
| **Порог большого txt/md** | Размер файла в мегабайтах, начиная с которого к текстовым файлам применяется сниженный лимит символов. | `5` МБ |
| **Заходить внутрь ZIP** | Индексирование файлов внутри ZIP-архивов как отдельных вложенных записей с путём вида `архив.zip → файл.txt`. Неизменившиеся архивы повторно не распаковываются. | `Включено` |
| **Предел файла в ZIP** | Максимальный размер распакованного файла внутри ZIP-архива для извлечения текста. | `20` МБ |
| **Извлекатель PDF** | Выбор механизма извлечения текста из PDF: встроенный безопасный обработчик на чистом Rust или внешняя утилита `pdftotext`. | `Встроенный` |
| **Путь к pdftotext** | Путь к исполняемому файлу внешней утилиты `pdftotext` (активен, если выбран внешний режим). | Пусто (не задан) |
| **Предел времени на файл** | Максимальное время (в секундах), отведённое на извлечение текста из одного документа в изолированном рабочем процессе. Защищает программу от зависания на сложных или повреждённых файлах. | `120` секунд |

## 4. Вкладка «Закрытые данные»

Защита конфиденциальных файлов и учётных записей от случайного прочтения и индексирования текста.

| Настройка | Что делает | Умолчание |
|---|---|---|
| **Встроенные правила защиты** | Неотключаемый список встроенных шаблонов безопасности: `.env*`, `*.env`, `.ssh`, `.gnupg`, `credentials`, `secrets`, `auth.json`, `logins.json`, `private_key`, а также файлы со словами `password` и `парол` не из исходного кода. Текст таких файлов **никогда не читается** даже при явном выборе. | Отображается в окне (всегда активно) |
| **Дополнительные шаблоны** | Пользовательский список дополнительных шаблонов файлов и папок, содержимое которых должно быть скрыто и защищено от извлечения текста. | Пусто (нет дополнительных) |

## 5. Вкладка «Поиск»

Параметры поискового движка, ранжирования и отображения результатов.

| Настройка | Что делает | Умолчание |
|---|---|---|
| **Словоформы** | Использование морфологического словаря русского языка (`morph.fst`). Позволяет находить документы при запросе в любой грамматической форме (падеж, число, род, время). | `Включено` |
| **Несколько слов** | Режим обработки многословных запросов:<br>• `Строгая фраза` — слова ищутся строго подряд в порядке запроса, на каждой позиции допускается любая форма лексемы.<br>• `Все слова` — слова могут находиться в любом месте документа, при этом совпадения точной фразы ранжируются выше. | `Строгая фраза` |
| **Число результатов** | Максимальное количество отображаемых карточек результатов в поисковой выдаче (от 1 до 500). При этом общее число совпадений всегда рассчитывается точно. | `200` |
| **Длина фрагмента (до / после)** | Количество символов контекста вокруг найденных слов, отображаемых в карточке файла в окне поиска. Все найденные формы слов подсвечиваются. | `140` / `300` символов |
| **Сортировка по умолчанию** | Начальный порядок отображения карточек результатов:<br>• `По соответствию` — сначала точные фразы, затем релевантность BM25;<br>• `Сначала крупные` — по убыванию размера файла;<br>• `Сначала новые` — по дате изменения файла;<br>• `По имени` — по алфавиту. | `По соответствию` |
| **Слова «книжных» папок** | Ключевые слова в путях папок, наличие которых относит файлы к категории «Книга». | `books ebooks литература library библиотека книг*` |

## 6. Вкладка «Обновление»

Управление автоматической синхронизацией поисковой базы с изменениями на дисках и автозапуском.

| Настройка | Что делает | Умолчание |
|---|---|---|
| **При запуске программы** | Автоматически выполнять разностную проверку изменений файлов на индексируемых томах сразу после запуска программы. | `Включено` |
| **Каждые N минут** | Интервал периодического фонового сканирования изменений на подключённых дисках в минутах (значение `0` полностью отключает периодический опрос). | `60` минут |
| **Запуск при входе в Windows** | Добавляет или удаляет запись программы в ветку реестра текущего пользователя (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`), не требуя прав администратора. | `Выключено` |

## 7. Вкладка «Данные и производительность»

Системные параметры хранения базы данных, кэшей индексов и распределения вычислительных ресурсов.

| Настройка | Что делает | Умолчание |
|---|---|---|
| **Папка данных** | Путь к каталогу хранения базы метаданных SQLite (`catalog.sqlite3`), индекса Tantivy (`index/`) и журналов (`logs/`). При смене пути программа предлагает перенести существующие данные на новое место или создать новую пустую базу. | `%LOCALAPPDATA%\ПоисКовичеК` (или рядом с `exe` в переносном режиме) |
| **Число рабочих процессов** | Количество параллельных процессов извлечения текста (`Poiskovichek.exe --worker`). Значение `0` задаёт автоматическое определение по числу доступных логических ядер процессора. | `0` (по числу ядер) |
| **Щадящий режим для HDD** | Ограничивает параллельное чтение не более чем одним потоком на физический диск, снижая износ механических головок жёстких дисков и устраняя подтормаживание системы. | `Выключено` |
| **Хранить журнал** | Количество дней хранения файлов журнала работы программы в папке `logs/`. Устаревшие записи автоматически удаляются. | `14` дней |
