# Замеры производительности программы «ПоисКовичеК»

В этом документе зафиксированы результаты контрольных замеров скорости работы и потребления ресурсов компонентов программы ПоисКовичеК в сравнении с целевыми показателями Технического задания (раздел 6).

## Характеристики тестовой машины

Конфигурация получена с помощью командлета `Get-CimInstance`:

- **Процессор**: AMD Ryzen 3 4300U with Radeon Graphics
- **Ядра / Потоки**: 4 физических ядра, 4 логических процессора
- **Оперативная память**: 32 ГБ (32 896 568 КБ / 31,37 ГиБ)
- **Накопитель**: INTEL SSDPEKNU512GZ (NVMe SSD 512 ГБ, интерфейс SCSI/NVMe)
- **Операционная система**: Microsoft Windows 11 Pro (64-бит)
- **Дата проведения замеров**: 26 октября 2026 г.

## Дополнительные замеры компонентов

- **Скорость морфологического токенизатора (`perf_tokenizer`)**: **208,8 МБ/с** (обработано 50,00 МБ текста, 8 583 482 токена за 0,239 с; цель ≥ 60 МБ/с).
- **Построение снимка каталога из SQLite на 200 тыс. записей (`perf_snapshot`)**: **0,216 с** (216 мс; цель ≤ 1,0 с).
- **Поиск фразы из 2 слов по 100 тыс. документов**: медиана **3,55 мс**.
- **Сохранение снимка 1 млн записей на диск**: **0,534 с** (размер `names.bin`: 221,67 МБ).

- **Исполняемый файл (`Poiskovichek.exe`)**: 19 331 584 байт (**18,44 МБ** / ~19 МБ, релизная сборка с LTO без отладочных символов).
